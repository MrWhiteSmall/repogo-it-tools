# IT-Tools · 本地实用工具箱

把活动说明做成二维码图片，把重复物资清单整理成一份，再看看一段文字有多少字符。页面在自己的电脑上运行，三项操作都在浏览器内计算。

## 获取完整运行包

- **没有安装 Git**：打开 [知识星球项目帖](https://wx.zsxq.com/group/15551241858142/topic/55521424585841544)，在附件中下载 `repogo-it-tools-macos-arm64.zip`，完整解压后按下文启动。附件含本次验证使用的运行环境。
- **已经安装 Git**：在终端运行 `git clone https://gitee.com/lushengjie/repogo-it-tools.git`，进入生成的文件夹。已核验无需 Gitee 登录即可克隆，随包运行环境的摘要与正式交付一致。

本次匿名检查中，Gitee 网页“下载 ZIP”返回的是网页，单独下载运行环境文件返回 403。因此这里以星球附件或上述 Git 克隆作为已验证的完整获取路径，不承诺网页 ZIP 可免登录下载。星球附件与公开仓库内容之间的文档发布状态更新不改变正式附件。

## 苹果芯片 Mac 开始使用

完整解压文件夹，运行 **启动.command**。脚本会校验并解压随包提供的运行环境，再打开 **http://127.0.0.1:4824/**。不用先装 Node、Python、uv、Docker，也不用注册模型账号。

本轮实测使用终端进入本文件夹执行 `bash 启动.command`；Finder 双击尚未单独验收。结束使用时运行 **停止.command**，重新打开可运行 **重启.command**。遇到系统安全提示，按系统的正常审核流程操作。

页面左侧可以选择二维码生成器、清单整理和文本统计。二维码页输入自己的文字或链接，立即预览，点击“下载二维码图片”取得 PNG；清单页每行一项，打开“移除重复行”，右侧即可得到结果。

使用说明见 [DEPLOY.md](DEPLOY.md)，故障处理见 [FAQ.md](FAQ.md)，开源来源和重新构建见 [SOURCE.md](SOURCE.md)。

这份运行包是三工具本地版；上游完整项目另有更多工具。中文菜单来自上游已有翻译，本包设为默认中文，并补齐这三项操作的字段和提示。原算法未改写。

实测：苹果芯片 Mac、随包 Node 22.21.1、Edge。Windows、Linux 和 Intel Mac 未实测，本包只附 macOS ARM64 环境。
